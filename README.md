# Ninisha Pradhan — Design Portfolio

Live portfolio of pages I designed and shipped at DaVinci Commerce (formerly Jivox).

**View live**: https://ninishapradhan.github.io/ninisha-design-portfolio/

## Contents

- `index.html` — portfolio landing page
- `homepage/` — DaVinci Commerce Agentic BrandStore homepage (React + SSR)
- `case-studies/` — Case studies, use cases, and landing pages (vanilla JS, server-rendered HTML)

All pages are static, fully interactive (animations, hover states, count-up stats, scroll reveals), and viewable on any modern browser. Designed and built end-to-end: brand, layout, motion, copy, and front-end implementation.
